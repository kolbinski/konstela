# Recenzje zewnętrzne

Opinie o materiałach Nagrody, zamówione u recenzentów spoza projektu. Trzymane w całości, bez skracania, bo wartość mają wtedy, gdy da się do nich wrócić i sprawdzić, co dokładnie powiedziano.

Prompty, którymi je zamawiano, leżą w katalogu głównym. Każda oferta ma własny prompt z własną personą i własnymi pytaniami o ryzyka tej konkretnej roli; `mk-prompt-recenzji.md` dotyczy pakietu ministerialnego, a nie oferty.
